One scaling note for your manager conversation
Listing every VIN in an ACL file doesn't scale to millions of cars.
 Real brokers use patterns — Mosquitto supports %u (username) and %c (client id):
pattern readwrite vehicle/%u/#
If each car's broker username is its VIN, that single line confines every car in
 the fleet to its own topics — no per-car config. Production brokers (EMQX, HiveMQ) 
 go further and pull ACLs from a database or derive them from the client's mTLS certificate.
  Worth knowing that the file approach is a dev-scale thing.
